## Proven vs. experimental

- Fracture is pinned to `642c00a8a2d3a95979e85bbfa3f62deee611a4a6`; reuse is governed by upstream MPL 2.0 code / CC BY-SA 3.0 content, with notices in the package. No new licensed assets were introduced for the scenery work.
- The original Chaos engine already contains substantially more campaign, character, D20, DM and voting logic than the Fracture spike. **Before expanding the migration, compare original-engine renderer replacement against individual feature porting**. Reuse existing original gameplay rules rather than rebuilding them in new code.
- Existing Fracture spike: independently authenticated native phone actors, native combat/navigation, small Chaos object inventory/crafting, partial D20 and NPC witness behavior, SSE-triggered phone refresh. **Not** full Crown Job / Dawn Bell / AI-memory / group campaign parity.
- Recent authored scenery vertical slice (Oct 30): `scenery-bridge.mjs` and `environment-rules.mjs`; `chaos-world.mjs` seeds **up to four Chaos-authored trees near distinct actor spawn areas, only on native-passable, unoccupied tiles**; phone `attack tree` or `chop tree` routes to a creative action with auto-approach, 3 damage per hit, separate save, collision cleared on destruction; `chaos-tv.ts` draws a tree/stump from authoritative snapshots; `world-change.mjs` includes scenery in authenticated notifications. **This is not destruction of native Fracture trees or buildings.**
- New regression coverage in `chaos-world.test.mjs`, `scenery-bridge.test.mjs`, `environment-rules.test.mjs`, `world-change.test.mjs`; the disposable real-server tree interaction test in `verify-native-objects.mjs` **passed** at source SHA `36de73fe69315d24eb9b1349a968195580ad8f15` ([run 41088458211](https://github.com/sifuentestrey/chaos-party-rpg/actions/runs/41088458211)): four real native strikes, second-actor broken-state agreement, real movement into the cleared tile, and saved destruction.
