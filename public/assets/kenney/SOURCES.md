## Coordinates

The packed sheets `dungeon.png` and `town.png` are 192 x 176 pixels with 12 columns, 11 rows, 16 x 16 tiles, and no gaps.
For numeric tile id i (zero based), source rectangle is `[(i % 12) * 16, floor(i / 12) * 16, 16, 16]`.
The spaced sheets have 1-pixel spacing (source pitch 17).

These are original downloaded assets, not generated imagery or extracted proprietary game content.
