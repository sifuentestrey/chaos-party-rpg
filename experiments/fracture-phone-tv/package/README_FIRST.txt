CHAOS PARTY — LOCAL FRACTURE TECHNOLOGY BETA

Each phone controls a separate saved character in Fracture's existing world.
Original Crown Job and Dawn Bell campaigns are not included; this is the
separate Fracture family beta. Original Chaos source and saves stay separate.

Double-click Start_Chaos_Party.command on the Mac.
Requires Node 22.18+ LTS (owner-tested baseline: 22.23.4), Git and first-install internet.
If macOS blocks opening a downloaded script, inspect it and run in Terminal:
  bash Start_Chaos_Party.command

Open the private host link from Terminal, open the shared TV, and join each phone
using its QR on the same Wi-Fi. New players create their character and tap Ready;
the host begins the adventure. Wardrobe later changes appearance only.
The phone is Action, Abilities, then Gear. Type what you want to try.

SHARED ADVENTURE RHYTHM
New rooms use Hybrid: explore one existing scene together. An enemy encounter
or the host's Gather attention pauses gameplay while everyone chooses at once.
Choose an action and optionally your class signature, then tap Ready. All ready
or 30 seconds starts bounded interpretation, five seconds of real gameplay,
then a four-second shared recap. A silent phone holds position. The host can
add 15 seconds. Unfinished actions need fresh Ready each round.
Enemies, movement, fire, effects and cooldowns pause during planning and recap.
STOP clears only your own action/ability and remains available throughout.

Moving into another scene or existing doorway opens a majority travel vote.
Approval asks native characters to walk or use the door; it never teleports.
STOP can leave you behind. Rejoin follows approved native routes and can be
blocked by real obstacles. The TV shows the active scene and shared progress.
Existing rooms stay Live until everyone regroups and the host starts Hybrid.

OPTIONAL ADVENTURE
The host can start The Refuge Trial once a living character joins The Refuge.
Talk to a native NPC, defeat a real monster, reach Glitch Woods and return home.
Progress is saved. Existing native quests/rewards continue independently.
New synthetic crafting is disabled: the game reuses verified existing map art.
Trees, tents, rocks and other supported existing objects have validated reactions;
unsupported actions explain their actual limits. NPCs remember witnessed trouble.

AI DM
On the private Mac host page, paste your Groq Free Plan key once and click
Connect AI DM. It saves, checks and enables the connection in one step.
Enabled connections are checked at launch; explicit OFF stays off. No key is
bundled. Hybrid batches unusual choices and narrates confirmed shared outcomes.
Offline play remains available when AI is off, unavailable or out of free quota.

Keep Terminal open. Control-C saves characters and stops only this launcher's
processes. Fracture lives in ~/Fracture-Chaos-Spike with its own database.
The host can bench/restore players without deleting saved characters.
Keep host and personal recovery links private. No paid service is required.
