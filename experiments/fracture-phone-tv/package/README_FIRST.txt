CHAOS PARTY — LOCAL FRACTURE TECHNOLOGY BETA

IMPORTANT: This is NOT the original Chaos Party game migrated to Fracture.
Crown Job, Dawn Bell, original character customization, D20/object/NPC memory
and campaign saves are not present. This is a separate native Fracture playtest.
Read docs/CHAOS_TO_FRACTURE_PARITY.md before treating it as a release.

Double-click Start_Chaos_Party.command on the Mac.
Requires Node 22.18+ LTS (owner-tested baseline: 22.23.4), Git and first-install internet.
If macOS blocks opening a downloaded script, inspect it and run this in Terminal:
  bash Start_Chaos_Party.command

Open the private host link from Terminal, open the TV, and join each phone using its QR.
Use the same Wi-Fi. Each phone controls its own character. Keep Terminal open.
The private host page can BENCH a player to free a 20-player slot without erasing their saved character.
Restore that player from the host page when another slot becomes available.
Keep personal recovery links private; only the host should use the host link.
Control-C saves characters and shuts down only this launcher's test processes.

The original Chaos Party game and saves remain separate.
Fracture lives in ~/Fracture-Chaos-Spike; its existing config and database are preserved.
No subscription, public hosting or paid AI service is needed.

Read experiments/fracture-phone-tv/README.md for controls, the optional adventure route,
credits and precise beta limitations. Read docs/FRACTURE_GAME_NIGHT_RELEASE.md for evidence.
Physical 2015 Mac + phone + TV acceptance remains unverified by cloud testing.
