# Chaos Party — Mac rehearsal test build

This is a test download, not a finished release. It contains the completed polish checkpoint, NOT the unfinished visual-release experiment. Published with the owner's permission for a first physical Mac/phone rehearsal.

[Download the Mac ZIP](https://github.com/sifuentestrey/chaos-party-rpg/raw/refs/heads/downloads/mac-rehearsal-da72db5/Chaos_Party_Mac_rehearsal_da72db5.zip)

1. Download the ZIP to your Mac and double-click to unpack.
2. Open `Chaos_Party_Mac` and double-click `Start Chaos Party.command`. Keep its Terminal window open.
3. Host a party and create a private room. Phones scan the QR using the same Wi-Fi as the Mac.
4. Try the Mac screen first; connect the TV afterward. Start with two phones.

If macOS blocks the launcher, right-click it and choose Open; report the exact message if it remains blocked. Keep previous installations and saves, if any, and use a NEW test room.

Source: `da72db54f490cef62e7ea1f68b79737d1867fc96`, clean source state. Intel and Apple Silicon runtimes included. No API key or paid AI is needed; narration is off by default. No environment or saved-campaign files are included.

Bundled-server smoke checks passed on Linux with two controllers, dice/actions and persistence; actual Mac runtime, TV/audio/LAN performance and family enjoyment remain unqualified. The full visual milestone and live AI DM qualification are unfinished.
